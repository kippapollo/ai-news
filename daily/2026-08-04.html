Alibaba drops Qwen 3.8-Max at 2.4 trillion parameters and promises weights next week, the first Max-class Chinese model to open

Qwen 3.8-Max activates roughly 95 billion parameters per token across a sparse mixture-of-experts built on the Qwen 3.5 substrate, ships a 1 million token context window, native multimodal text and vision input, and three reasoning-effort levels. Bench scores land at 93.0 on PaperBench above GPT-5.6 Sol and Claude Opus 4.8, 82.8 on IFBench versus Sol's 72.7, and 86.6 on Terminal Bench 2.1. API access is live immediately through DashScope in Beijing, Singapore and Virginia with OpenAI-compatible and Anthropic-compatible endpoints; the Hugging Face and ModelScope open-weights drop is scheduled for next week. Alibaba shares jumped as much as 7.3 percent in Hong Kong, the strongest single-day move in nearly a month.

The Register · 2026-08-03 · Source ↗

Alibaba unveiled Qwen 3.8-Max on Monday, its largest artificial intelligence model to date and the first Max-class Qwen release the company has committed to open-source. The model activates roughly 95 billion of a 2.4 trillion-parameter mixture-of-experts on any given token, ships a 1 million token context window, and accepts text, image, and video input through the same interface. Three reasoning-effort levels are exposed to callers: xhigh (default), medium, and low, with each level trading latency for score. Default output is 65,536 tokens, expandable to 131,072. The technical release note calls the model "the first Max-class Qwen designed for autonomous coding, complex research, and long-horizon agentic tasks."

Access is live immediately through Alibaba's DashScope API with endpoints in Beijing, Singapore, and Virginia, and the SDK supports both OpenAI-compatible and Anthropic-compatible request formats so callers can point existing agent stacks at Qwen without a rewrite. The open weights, alongside a companion Qwen 3.8-27B model, are scheduled to land on Hugging Face and ModelScope "next week," per the announcement. That timing puts the release inside the first full trading week after EU AI Act General-Purpose AI enforcement powers activated 48 hours earlier, and inside the trailing week's trillion-dollar drawdown across the AI chip complex.

Benchmarks that beat GPT-5.6 Sol and Claude Opus 4.8 on paper

The published benchmark set is aggressive. Qwen 3.8-Max posts 93.0 on PaperBench, above GPT-5.6 Sol at 88.4 and Claude Opus 4.8 at 91.7 per Alibaba's tables. IFBench, the instruction-following evaluation that has been the wedge OpenAI used most heavily in its GPT-5.6 marketing, lands at 82.8 versus Sol's 72.7. Terminal Bench 2.1, the coding-agent benchmark that DeepSeek's V4-Flash-0731 upgrade set the open-weights bar for at 82.7, sits at 86.6. Multimodal dialogue accuracy on Alibaba's internal 526-team competition set reads 0.853, beating 458 of the 526 human teams. On the Arena.AI text arena, the model debuts as the highest-ranked Chinese entrant, trailing Claude Fable 5 and Claude Opus variants but ahead of every open-weights competitor.

Alibaba's release brochure is careful to note where Qwen 3.8-Max does not win. General-purpose reasoning benchmarks tilt US, and specific closed-model comparisons on HLE text-only and GPQA Diamond leave Sol and Opus 4.8 in front. Multimodal video reasoning is still catching up to Gemini 3.5 Pro's numbers. The bet, spelled out inside the technical note, is that a first-tier Chinese frontier model shipped under an open-weights license alongside an aggressive DashScope price schedule reshapes the enterprise procurement conversation in the second half of 2026, particularly for buyers preparing Article 53 GPAI training-data documentation who have not yet chosen a lead vendor.

"They're clearly dominating on open models right now, and I wouldn't be surprised if they start dominating at the frontier either by the end of this year or next year." — Clément Delangue, Hugging Face CEO, on The Register

Pricing lands under Sonnet 5, above Luna

Cloud pricing through QwenCloud lists $2 per million input tokens, $6 per million output tokens, cached implicit reads at $0.25, cached explicit reads at $0.17, and cached explicit writes at $2.50. That schedule matches Anthropic Claude Sonnet 5's $2 input, sits $4 per million cheaper than Sonnet 5's $10 output, and lands well above OpenAI GPT-5.6 Luna's $0.20/$1.20 as re-priced by AWS Bedrock last Wednesday. The positioning is deliberate: Alibaba wants to sit as the enterprise-tier alternative to Sonnet 5 at the same input rate, cheaper output, and with an open-weights escape hatch that neither Anthropic nor OpenAI offer for their premium tiers. DeepSeek V4-Flash-0731 remains cheaper still at $0.14/$0.28 for callers who can trade a Terminal Bench 2.1 point or two for another order of magnitude on price.

Capabilities the demo reel emphasized

The launch demo reel emphasized what Alibaba calls "app-to-app translation" and "video-first computer use." The model can recreate a functional web application from a set of UI screenshots, generate interactive educational animations in Manim from a spoken description, and convert a two-dimensional floor plan into a rotatable 3D visualization. On the coding side, the emphasis was autonomous multi-hour research tasks: the model takes a research question, plans and executes web searches, writes and runs Python analysis, and produces a written report with figures and citations. The demo included a live example in which the model was asked to reconstruct the Suno-GEMA verdict facts from public sources and produce a 2,000-word summary; the output was displayed inside a Beijing keynote streamed simultaneously to a paywalled DashScope customer preview event.

"Chinese AI strategy emphasizes accessibility and cost over the closed-model approaches that have dominated US frontier releases. Open-weight is becoming industry standard among Chinese developers." — Tech Startups, on the open-weights direction

What the market did

Hong Kong-listed Alibaba shares jumped as much as 7.3 percent on Monday, closing up 6.9 percent in the strongest single-day performance in nearly a month. US-listed BABA closed up 5.8 percent. The move landed in a broader trading day that saw the AI chip complex extend the prior week's drawdown, with AMD off 7.2 percent on the day and Nvidia off 2.4 percent, so the Qwen release did not carry the sector — the market took it as a company-specific catalyst rather than a bullish sector print. Anthropic CEO Dario Amodei's response, delivered via a blog post published inside the Monday trading window, restated the company's opposition to Chinese-origin models, distilled models, and models "lacking rigorous safety metrics" being permitted in US enterprise procurement. The post did not name Qwen 3.8-Max but was widely read as a direct response.

The open-weights question is now four wide

With Qwen 3.8-Max's weights arriving next week alongside Moonshot's Kimi K3 (2.8T, MIT-family license, on Hugging Face since July 27), DeepSeek V4-Flash-0731 (284B/13B, MIT, live), and Thinking Machines Inkling-Small (276B/12B, Apache 2.0, live), the frontier-scale open-weights list runs four models wide before the end of the first week of August. Meta's paid Muse Spark 1.1 sits as the largest US-origin open-weights entrant at a restrictive license; Anthropic's frontier line remains fully closed. What Delangue's framing captures — that the Chinese labs are running away with the open-model conversation — is now a quantitative claim readers can check against Hugging Face's own download counters, which last week showed Kimi K3 crossing 99,000 downloads inside its first 24 hours.

Microsoft's MAI-Realtime surfaced Monday as a hidden preview entry in MAI Playground, first spotted by TestingCatalog on Saturday and picked up by Crypto Briefing in a Monday write-up. MAI-Realtime is Microsoft's first native full-duplex voice model, meaning the system can listen and speak simultaneously rather than following a rigid turn-based pattern. Two voices are exposed in the preview — Victoria and Grant — and a configurable turn-taking parameter called Switchboard mode governs how aggressively the model interrupts or defers to the caller. The model handles mid-conversation language switching without a context reset.

Language support at preview spans English, German, Spanish, French, Italian, Portuguese, Japanese, Korean, Chinese, Dutch, Hindi, Indonesian, Arabic, Russian, Turkish, Vietnamese, and Thai — 17 languages total. The model does not produce singing or non-speech audio; that is by design, to keep the safety surface narrow at preview. A debug panel shows latency figures and processing visibility, letting reviewers watch the round-trip time between input and first spoken output. TestingCatalog's write-up describes the voice quality as "noticeably more natural than what Copilot's voice mode currently delivers."

The strategic point: closing the OpenAI dependency

MAI-Realtime completes Microsoft's vertically integrated voice stack. MAI-Transcribe-1 handles listening. MAI-Voice-1 (now MAI-Voice-2 in production) handles synthesis. Azure Speech's Voice Live API had been routing to OpenAI's GPT-Realtime for the bidirectional path — the missing piece for a full end-to-end Microsoft-owned voice agent. MAI-Realtime closes that dependency. Microsoft has not publicly detailed pricing, availability timeline, or whether MAI-Realtime will replace GPT-Realtime as the default engine inside Voice Live, but the vertical-integration read is straightforward: Microsoft now owns the full audio pipeline for Copilot voice.

"The model processes audio in real time, going both directions at once, which is what makes voice feel genuinely conversational rather than robotic." — Crypto Briefing, on MAI-Realtime's core design

What preview does not answer

No performance benchmarks are published, no MOS (mean opinion score) numbers, no formal latency budget, and no pricing tier or public developer access has been announced. The absence of a benchmark table at preview is characteristic of a hidden-preview asset that Microsoft has not yet green-lit for launch. Voice-model comparisons that will matter when Microsoft does formally launch: OpenAI's GPT-Realtime end-to-end latency (~320ms round-trip at production quality), Google's Gemini Live streaming latency (~280ms), and Anthropic's Claude voice preview (which does not yet ship a fully full-duplex model). Microsoft has said nothing publicly about MAI-Realtime; the Playground appearance is the first evidence the model exists.

Where MAI-Realtime lands inside the enterprise voice-agent conversation

The immediate integration target is Microsoft 365 Copilot's voice mode, currently powered by GPT-Realtime with a Voice Live wrapper. Enterprise deployment of Copilot voice has historically been held back by two factors: latency at scale (each call routing through OpenAI's inference plane added measurable round-trip time versus Azure-hosted alternatives) and a data-residency concern from EU customers who wanted the voice path inside Microsoft's own Azure region boundaries. MAI-Realtime closes both. Expect a formal Copilot integration announcement in the window between Microsoft's next Foundry release and Ignite, though nothing has been confirmed.

The Copilot CLI update lets a caller start Copilot, Claude Code, or Codex sessions in an isolated Git worktree so each agent operates against its own working copy of the repository. The same release fixed extension slash commands running once per invocation, corrected inline image rendering, and made piped runs fire sessionEnd hooks per completed turn. The changelog framing is unusual for GitHub: this ships as an agent-orchestration primitive rather than a Copilot ergonomics fix.

GitHub's Monday changelog for Copilot CLI added first-class support for starting Copilot, Anthropic Claude Code, and OpenAI Codex sessions inside isolated Git worktrees. Each session gets its own working copy of the repository, checked out to a separate branch, running against the same underlying object store — the standard Git worktree pattern, but wired directly into Copilot CLI's session-launch flow so a caller does not need to manage worktree lifecycle manually. The immediate benefit is that a developer running three agents in parallel — a Copilot-driven refactor, a Claude Code exploration, and a Codex test-writing pass — no longer has to serialize the work through a single working directory or spawn three separate repository clones.

The change is small in Copilot changelog terms but structurally significant. GitHub is telling the ecosystem that Copilot CLI is the orchestration layer for concurrent agent work, and that competing agent runtimes (Claude Code, Codex) are first-class citizens inside that orchestration rather than second-class alternatives to be evangelized against. The worktree pattern also composes cleanly with Anthropic's own Claude Agent SDK Worktree isolation mode, which had been the higher-friction way to get the same primitive.

Smaller fixes in the same release

The paper's method section walks through the exact anatomy of the poisoning.
