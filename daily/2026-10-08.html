OpenAI matches the floor: GPT-6.1 Sol repriced to $1 input and $5 output per million, 36 hours after DeepSeek V5.

OpenAI pushed GPT-6.1 Sol pricing down 50 percent on Thursday morning at 09:30 Pacific, dropping input tokens to $1 and output to $5 per million with a 95 percent cached-input discount, and cutting Ultrafast on Cerebras from $60/$300 to $30/$150. GPT-6 Astra fell to $1.50/$7.50 from $2/$10. The ChatGPT Pro 500 tier at $500 per month doubled its Ultrafast inclusion to 100 million output tokens; Business Premium at $500 per seat added a 50-percent Dots-agent compute-pool uplift at unchanged price. Sam Altman announced the move live from a makeshift press stop in Mountain View two hours before the OpenAI blog went up. The repricing lands 36 hours after DeepSeek pulled hosted frontier inference to $0.14 input and $0.56 output on V5 Preview under MIT, and 48 hours after Qwen 5.0 Preview opened at $0.70 and $2.80.

Tech · Economic · OpenAI Blog · 2026-10-08 · Source ↗

OpenAI posted the GPT-6.1 Sol repricing to the platform blog at 11:42 Pacific Thursday, two hours after Sam Altman confirmed the move at a hallway press stop at the Rosewood Sand Hill. The headline numbers: GPT-6.1 Sol drops from $2 input and $10 output per million tokens to $1 and $5, with the 90 percent cached-input discount widened to 95 percent and extended to repeated system prompts for the first time. GPT-6 Astra, the previous Pro-tier default, falls from $2 to $1.50 input and from $10 to $7.50 output. GPT-6 Astra Flash drops to $0.30/$1.20, Astra Nano to $0.10/$0.40. Ultrafast on Cerebras wafer-scale silicon falls from $60/$300 to $30/$150 and keeps the 300-tokens-per-second output floor.

The ChatGPT Pro 500 tier launched at DevDay on October 6 doubled its Ultrafast inclusion to 100 million output tokens per month at unchanged $500 price. Business Premium at $500 per seat added a 50-percent Dots-agent compute-pool uplift. OpenAI's blog explicitly flagged the DeepSeek V5 Preview release Wednesday morning Pacific time at $0.14 input and $0.56 output under MIT as the pricing pressure that forced the move, and acknowledged that Qwen 5 Preview at $0.70/$2.80 under Apache 2.0 had already pulled the floor beneath GPT-6.1 Sol's prior position.

"We said at DevDay that frontier intelligence should get cheaper every year. The expected cadence was annual. What happened yesterday morning compressed that into 36 hours. We priced for that reality." — Sam Altman, OpenAI CEO

Benchmarks the repricing announcement reiterated: GPT-6.1 Sol holds 83.2 on DeepSWE v1.1, 74.6 on OSWorld 2.0, 93.1 on MMLU-Pro, 71 percent on CWE-bench, and 61.8 on ARC-AGI-2 private, placing it above DeepSeek V5 Preview's 79.1 on DeepSWE and 68 percent on CWE-bench and leaving Opus 5.5 at 80.1 and Argon at 77.9 in third and fourth. The gap on cost-adjusted benchmark performance tightens. GPT-6.1 Sol at $5 output serves roughly 9x V5 Preview's cost on hosted inference for a four-point DeepSWE lead and a three-point CWE-bench lead, down from 18x cost-ratio before the Thursday cut.

Mira Murati, in a separate 11:00 call with OpenAI Platform partners, flagged two structural changes to the pricing architecture. First, the cached-input discount extends to repeated system prompts, letting enterprise customers maintaining long persona templates pay 5 cents per million on the system half of each call. Second, the per-task Vault memory attestation shipped Wednesday now counts cached tokens on first use rather than requiring reload per task, cutting per-task overhead costs 60 to 80 percent for Dots deployments running against external MCP connectors.

"The pricing update is not a reaction to DeepSeek V5 alone. It is the first move in a two-step. The second move is Codex Cloud and Dots capacity reserved on Nvidia Blackwell. We will not match on capex. We will match on price-per-token and win on reliability." — Mira Murati, OpenAI CTO

SemiAnalysis's Dylan Patel marked the frontier pricing-floor consolidation in a note posted an hour after OpenAI's blog: "Western frontier output pricing has formally compressed from $10 to $5 for Sol-class, from $20 to $7.50 for Astra-class in 72 hours. The $0.56 open-weights floor is a different market segment. The two-tier equilibrium is Western frontier at $5, open-weights hosted at under a dollar, and Mythos-class defender inference at $90. Enterprise choice is now about reliability, not capability inside the top band."

Anthropic's response is scheduled for Friday morning, per a note Jared Kaplan posted to X an hour before the Thursday open. Google's follow-up on Gemini 4 Argon pricing is understood to be scheduled for Monday after the three-day U.S. holiday weekend. Cognition ships Devin 3.1 with cross-repo memory sync and publishes Memory Spec v1.0 under Apache 2.0.

Tech · Cognition Blog · 2026-10-08 · Source ↗

Devin 3.1 adds cross-repository memory sync and a public Devin Memory Spec v1.0 under Apache 2.0, with GitHub Copilot Enterprise shipping compatible readers inside the same day.

Cognition posted the Devin 3.1 release notes at 09:30 Pacific Thursday, 23 hours after Devin 3.0 shipped Wednesday morning with Branch Preview and per-repository persistent memory. 3.1 adds cross-repository memory sync via a user-controlled GitHub manifest file at .devin/sync.yaml and publishes the Devin Memory Spec v1.0 under Apache 2.0 as a public standard. The spec defines a JSON Lines schema for agent memory with mandatory fields for provenance, scope, timestamp, hash, and attestation.

GitHub Copilot Enterprise shipped a compatible reader at 11:00 Pacific Thursday, allowing Copilot to read memory files written by Devin and Cursor Composer. Cursor Composer 2.2 shipped two hours later with Memory Spec v1.0 as the default. Replit Agent 2.0 shipped at 14:30 Pacific Thursday with Memory Spec v1.0 compatible across all three directions. OpenAI Codex Cloud confirmed Memory Spec v1.0 support shipped behind a feature flag inside the day with public release scheduled for October 20.

"Devin writes memory, Cursor reads memory, Copilot audits memory, Codex writes memory. The user owns the file. The system is the file. The spec is Apache 2.0. The agent-to-agent handoff pattern we have been waiting on for 18 months shipped as a public standard inside a single day." — Scott Wu, Cognition CEO

Memory Spec v1.0 ships with reference implementations in Go, Python, Rust, and TypeScript, maintained in the cognition-ai/memory-spec repository. The spec defines three memory classes: ephemeral (per-session), persistent (per-repository), and shared (cross-repository via sync manifest). Devin 3.1 pricing holds at $500 per month per seat for Devin Team and $2,000 per seat for Devin Enterprise.
