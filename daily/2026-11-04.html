Anthropic ships Message Threads in public beta cutting time-to-first-token 35 percent on long chats.

The Decoder · 2026-11-03 · Source ↗

Anthropic shipped Message Threads as a public beta on the Claude platform. The client sends only what changed since the last message; the full conversation stays encrypted in server memory and expires after five minutes of inactivity. Time to first token drops roughly 35 percent for requests between 500,000 and 1,000,000 tokens. Token usage is unchanged because Claude still reads the full history. The feature is available on the Claude Platform and through AWS, Microsoft Foundry and Google Cloud, aimed at coding agents, computer-use agents, and multi-document workflows.

Anthropic shipped Message Threads as a public beta on the Claude platform on November 3. The design change is simple: instead of the client resending the entire conversation on every API call, the server keeps the full conversation encrypted in memory for five minutes after the last message, and the client sends only the delta since the last message. Token usage is unchanged because Claude still processes the full history on every turn; the latency win comes from not re-transferring hundreds of kilobytes of JSON on each request.

What it changes

Time to first token drops about 35 percent for requests between 500,000 and 1,000,000 tokens, which is the dominant scale for computer-use agents, coding agents, and multi-document pipelines. The 35 percent figure is Anthropic's; there is no independent benchmark yet. Message Threads is available on the Claude Platform directly and through AWS Bedrock, Microsoft Foundry and Google Cloud's Vertex AI integration. The five-minute TTL is a server-side choice that turns the stateless chat API into a short-lived session; after the TTL expires, the next call falls back to full-context resend.

What Anthropic is not saying

The release does not specify which Claude models carry the feature. The coverage names no specific latency numbers for 100K or 200K-token conversations (the common case for most API users), and gives no indication of how Message Threads interacts with Anthropic's prompt-caching feature, which the company has been iterating on since early 2025.

Anthropic activates SynthID-Text watermarking globally across Mythos 5 and the Opus 4.7, 4.6 and Sonnet 4.6 fleet.

Pasquale Pillitteri · 2026-11-03 · Source ↗

Anthropic activated SynthID-Text invisible watermarking on November 3 across Claude Mythos 5, Opus 4.7, Opus 4.6 and Sonnet 4.6 on the Claude Platform API, with Amazon Bedrock following within days. The watermark is embedded in word choices (not whitespace or metadata) and does not apply retroactively to pre-November-3 output. The driver is EU AI Act Article 50 under Regulation 2024/1689, effective August 2 2026, which requires machine-readable marking of synthetic content; pre-August-2 models have a transition period ending December 2. Anthropic applies the watermark globally because it cannot yet scope the feature by region. Anthropic's own Claude Content Checker does not detect the watermark.

Anthropic activated SynthID-Text invisible watermarking on November 3 across Claude Mythos 5, Opus 4.7, Opus 4.6 and Sonnet 4.6 on the Claude Platform API. Newer models already carried the watermark. Amazon Bedrock follows "within a few days." The watermark is applied globally at launch because Anthropic cannot yet scope the feature by region; customers who need unmarked output on specific models do not have an opt-out.

How it works

The technique is Anthropic's implementation of Google DeepMind's SynthID-Text (described in the 2024 Nature paper), which embeds a signal in the model's word choices by modulating sampling randomness with a secret key and the preceding words. Importantly, this is not metadata, not whitespace manipulation, and not invisible Unicode; it lives in the actual tokens emitted, which makes it robust to copy-paste but readable only by someone with the detector and the key. The watermark does not apply to pre-November-3 output.

Why now

The driver is the EU AI Act. Regulation 2024/1689 Article 50 (effective August 2 2026) requires machine-readable marking of synthetic content; providers of models placed on the market before August 2 have a transition period ending December 2 2026. Anthropic is running ahead of the deadline. One operational wrinkle: Anthropic's own Claude Content Checker is not yet integrated with the detector, which means enterprise customers who build pipelines around Anthropic's detection tooling cannot yet recover the signal through official channels.
