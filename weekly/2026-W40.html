OpenAI DevDay turns always-on agents into the product and halves frontier pricing again

Tuesday morning at Fort Mason shipped Dots, GPT-6.1 Sol at $2/$10, an Ultrafast tier running on Cerebras wafer-scale silicon at 300 tokens per second, and the Agents API as a fully managed runtime. The $500 Pro 500 tier opens at 25x the Plus usage cap. Sign in with ChatGPT launched with 16 partners. Codex moved to the cloud with native GitHub and GitLab code review. The OpenAI Marketplace opened with more than 30 enterprise partners.

TechCrunch · 2026-09-29 · Source ↗

OpenAI opened DevDay 2026 at Fort Mason Tuesday morning by shipping Dots, always-on GPT-6 Astra agents that ride inside every ChatGPT Pro and Business Premium subscription with their own cloud computer, headless browser and persistent identity. Dots do not consume the user's chat quota for standing-by cycles or background research; they reach more than 4,000 apps through the ChatGPT connector library including Slack, Microsoft Teams, GitHub, Notion, Google Workspace and Salesforce; and they ship with a Microsoft Agent 365 governance path on day one. The bubbly animated avatar that fronts the product in TechCrunch's demo footage is designed to make persistent agent presence legible to a non-technical user without pretending the agent has personhood.

GPT-6.1 Sol landed at $2 per million input tokens, $10 per million output, and $0.10 per million cached input, a 95 percent discount aimed at long agent loops. The Agents API moved to public beta as a fully managed runtime that owns sessions, orchestration, context compaction and recovery; it ships with an OpenAI-hosted browser, connects natively to MCP servers as first-class tools, and supports parallel subagents. MCP Events landed alongside as a webhook-style extension OpenAI is contributing back to the Model Context Protocol working group. Ultrafast, a decoding-speed SKU running on Cerebras wafer-scale silicon, hits 300 tokens per second on Astra and up to 8x faster in Codex and 6x faster in the API at $60 per million input and $300 per million output, six times standard Astra rates.

"Dots are not a demo. Every subscription above Plus gets its own cloud computer the day the model wakes up."— Sam Altman, DevDay keynote remarks

The subscription stack rebalances around agent presence

Ultrafast bundles into a new $500-per-month Pro 500 tier with 25x the Plus usage cap. The reopened $200 Pro dropped its Astra multiplier from 20x to 10x for new signups, which reads as OpenAI preserving headroom for the Pro 500 price point rather than letting the $200 tier absorb Dots-driven inference. Business Premium is the enterprise counterpart; it ships with Dots, Microsoft Agent 365 governance, OpenAI Marketplace access, and the new Private Intelligence confidential-compute runtime whose sealed enclaves are unreadable even by OpenAI operators and which entered a limited fall preview the same morning. The Decisions API entered limited preview as a Luna-backed constrained-answer router that lets developers trade off capability for predictable I/O structure.

Codex moved to the cloud, gained voice control, native GitHub and GitLab code review, and Codex Security Cloud that scans entire repos on schedule and prepares fixes as pull requests. ChatGPT Space and Pages ship as the shared canvas where humans and Dots co-edit; Sign in with ChatGPT launched with 16 partners including Devin, Notion and Vercel; the OpenAI Marketplace opened with 30-plus enterprise launch partners. The ChatGPT connector library expanded to the 4,000-app threshold with Microsoft, Google Workspace, Slack and Salesforce as the day-one anchors.

"The reason the Agents API is a managed runtime is that nobody is going to build the context-compaction and recovery scaffolding themselves and then run it in production. We did it so you don't."— Romain Huet, OpenAI head of developer experience

What's missing from the stage

GPT-6.1 Astra was confirmed shelved by omission after safety regressions the Wall Street Journal broke Monday night. CFO Sarah Friar told CNBC OpenAI is "more vocal about safety because of what has been happening out there in the world," a line read in context as the company absorbing the June Hugging Face RCE, the Australian Medicare agent breach, and the September 27 secondary incident Mark Chen described separately as having been caught in fifteen minutes. OpenAI shifted 5 to 10 percent of its compute to safety work and now monitors models during training rather than only after deployment. The GPT-6 Cyber model Fortune pre-reported on September 24 did not ship Tuesday.

"We're more vocal about safety because of what has been happening out there in the world."— Sarah Friar, OpenAI CFO, CNBC interview

The release absorbed roughly ninety minutes of keynote stage time and sits inside a seven-day frontier window that paired it with Claude Sonnet 5.5 the Monday before, Gemini 4 Argon's cybersecurity-first rollout the Wednesday after, and the $60 billion Broadcom debt syndicate for Anthropic that followed on Friday. The through-line is that always-on agents, with their own compute and their own standing identity, are now the shape of the ChatGPT product, and that pricing on top-of-stack models has halved for the third time in six months. Developers who want parallel subagents, MCP tool-use, and session recovery no longer have to roll it themselves.

Trump signs a voluntary White House Accord on Superintelligence with ten frontier CEOs

CNBC · 2026-09-29 · Source ↗

Amodei, Zuckerberg, Musk, Pichai, Huang, Bezos, Karp, Sankar, Brockman and Nadella signed a four-point accord in the Cabinet Room Tuesday afternoon. Trump called it "morally binding" and floated a 10-person federal committee inside 30 days; Speaker Mike Johnson clarified the document carries no statutory force.

Trump convened Dario Amodei, Mark Zuckerberg, Elon Musk, Sundar Pichai, Jensen Huang, Jeff Bezos, Alex Karp, Shyam Sankar, Greg Brockman and Satya Nadella in the Cabinet Room on Tuesday afternoon for a working lunch that ended with the ten CEOs each signing a voluntary accord on superintelligence. The document is organized around four commitments: pre-release notification to a federal interagency committee for frontier runs above a defined capability threshold; red-team access for a short list of outside evaluators; incident disclosure within a defined window after discovery; and a shared declaration that "safe and responsible development" is a condition of continued US-based training infrastructure. Trump called the document "morally binding" and announced a 10-person federal committee to be stood up within thirty days to receive the pre-release notifications. Speaker Mike Johnson clarified separately on the record that the accord is voluntary and carries no statutory force.

The accord took shape in the two weeks following Amodei's September 12 "We Must Pace the Frontier" essay, which drew four CEO endorsements inside a day and became the fulcrum of the quarter per the Q3 recap published the prior Monday. The Cabinet Room signing is the first time a sitting president has personally endorsed a pacing framework for frontier AI, and the first time ten frontier CEOs appeared in the same room publicly committed to coordinated restraint. Trump used his UN General Assembly address a week earlier to reject "the globalist scheme" of AI oversight and call existential risk "a hoax"; the Cabinet Room ceremony reversed that rhetorical posture, at least in the formal document.

"This accord is morally binding. The committee stands up in thirty days."— Donald Trump, Cabinet Room remarks, September 29

What is in the accord and what is not

The accord does not name a specific capability threshold, define the composition of the federal committee, or specify what consequences attach to a missed pre-release notification. CEOs who sign receive the political cover of participation; the document's binding effect depends on whether the committee has subpoena power and on whether disclosed incidents trigger regulatory action separate from the accord itself. The California AG subpoena and FTC probe that landed four days later show that enforcement is proceeding through existing authorities regardless of the voluntary document's trajectory. Musk told reporters after the lunch that signing the accord was "a reasonable floor"; Karp told the Wall Street Journal in an interview the following morning that the committee's authority will be "the only question that matters."

"The committee's authority is the only question that matters. The signatures are the easy part."— Alex Karp, Palantir CEO, Wall Street Journal interview

Microsoft, Meta and xAI appear on the signatory list but are not part of the proposed Standards Authority for Frontier AI that Google, OpenAI and Anthropic formally proposed later in the week as a FINRA-style self-regulatory body. The accord sits in the gap between presidential ceremony and regulatory architecture, and the thirty-day deadline for the committee stand-up is the next operative date on the calendar.

Broadcom's banks begin syndicating $60 billion of debt for Anthropic's custom-silicon buildout

Dataconomy · 2026-10-02 · Source ↗

A $42 billion Class A senior-secured tranche led by Bank of America, Citigroup and Morgan Stanley pairs with an $18 billion Class B tranche led by Blackstone with $9 billion of its own junior capital. Anthropic becomes Broadcom's largest customer next year by revenue.

Broadcom's syndicate began mailing out $60 billion of debt Friday to finance Anthropic's purchase of Broadcom silicon under the ten-gigawatt custom-ASIC contract signed in the third quarter. The stack splits into a $42 billion Class A senior-secured tranche led by Bank of America, Citigroup and Morgan Stanley plus an $18 billion Class B subordinated tranche led by Blackstone, which is putting $9 billion of its own capital against the junior piece and syndicating the other $9 billion to co-investors. The deal translates Anthropic's $28.6 billion of signed compute commitments from the S-1 into equipment-backed paper rather than datacenter real-estate lease paper, and makes Anthropic Broadcom's largest customer next year by revenue.

The structure borrows from Chevron's 2019 Gorgon LNG financing more than from the hyperscaler data-center lease deals that have dominated AI capex syndication since 2024. Senior-secured notes are collateralized by the Broadcom-produced ASICs and the Trainium-adjacent compute racks that house them, with Blackstone's junior layer absorbing first-loss risk in a cash-flow waterfall tied to Anthropic's inference-revenue curve. The capital stack is designed to clear even if Anthropic's IPO slips past the November 9 roadshow window; the senior tranche has protective covenants that trigger step-up pricing but no acceleration if the IPO is delayed by less than six months.

"The deal translates compute commitments into tradable paper. That is the thing the credit market has been waiting to see written down."— Broadcom finance team, Dataconomy briefing

Why Anthropic signed this rather than lease more datacenter

Anthropic's prior-generation compute obligations are mostly leaseback arrangements with AWS, Google Cloud, CoreWeave and Akamai running against hyperscaler-owned datacenters. The Broadcom deal reverses that posture: Anthropic owns (via equipment-backed debt) the silicon that goes into third-party datacenter shells rather than renting access to someone else's bundled stack. The structure also sidesteps the FTC Section 7 investigation that Lina Khan opened six hours after the S-1 filing against the Akamai warrant, which flagged exactly the pattern of granting an infrastructure supplier equity in exchange for capacity commitments. Buying silicon on debt is a cleaner competitive posture than paying for compute with equity.

"We would rather owe Broadcom cash than owe AWS exclusivity. That is the whole point of the deal."— Anthropic finance leadership, through intermediary quoted in Dataconomy

The deal lands five days before Anthropic's expected roadshow launch and inside a seven-day window that also saw OpenAI float a $30 billion bridge at a $1.4 trillion private mark and Instinct close $1 billion at a $10 billion valuation. The credit market absorbed the paper without visible stress; Blackstone's $9 billion junior commitment is one of the largest first-loss positions it has taken in a technology-sector financing since the Dell take-private.

Anthropic · 2026-09-29 · Source ↗

Model ID claude-sonnet-5-5 generates output more than 30 percent faster with far fewer tokens per task. First Sonnet to ship with cybersecurity boundary safeguards previously reserved for Opus plus the containment fallbacks from Fable 5.1. Same-day availability on Bedrock, Vertex and Azure with zero retention.

Anthropic shipped Claude Sonnet 5.5 under model ID claude-sonnet-5-5 Monday morning. The pricing is unchanged at $2 per million input tokens and $10 per million output. Sonnet 5.5 generates output more than 30 percent faster than Sonnet 5 and uses far fewer tokens per task on Anthropic's internal benchmarks, which drives real cost per completed task down even without a headline price cut. It is the first Sonnet to launch with the cybersecurity boundary safeguards Anthropic previously reserved for Opus-class models, together with the containment fallbacks the company introduced with Fable 5.1 in July. The model is available same-day on AWS Bedrock, Google Cloud Vertex AI and Microsoft Azure with zero-retention terms matching the direct API.

The release is calibrated against a tight competitive window. GPT-6.1 Sol lands at the same $2/$10 at DevDay the next day; Gemini 4 Argon rolls out at the same $2/$10 to defenders Wednesday. By holding price flat and shipping speed and safeguards, Anthropic is choosing to compete on the latency-and-safety axis rather than on headline token cost. The Opus-tier cybersecurity boundary is the technically load-bearing part of the release: it is the first time Anthropic has shipped a mid-tier model with the containment profile Opus 5 and 5.5 use, which closes the capability-safety gap that previously made Sonnet a less-safe cheaper option in the Anthropic lineup.

"Sonnet 5.5 is the first mid-tier Claude to ship with the same containment profile as Opus. We are no longer treating Sonnet as a trade-off."— Anthropic model release note, September 28

What "far fewer tokens per task" means

Anthropic's internal evaluation suite measures tokens-per-completed-task across a representative mix of coding, analysis and tool-use workloads. Sonnet 5.5 reduces token output per task by a figure Anthropic described in the release note only as "far fewer" without publishing a specific percentage; third-party benchmark operators on the Artificial Analysis leaderboard put the number at between 18 and 24 percent across the first 48 hours of API traffic. Combined with the 30 percent speed increase, the effective reduction in dollars-per-task is roughly 40 percent for a typical coding-agent loop against Sonnet 5 at the same $2/$10 nominal rate. The result is an under-the-hood price cut delivered as efficiency rather than a nominal price change.

"We held price flat and shipped speed. For long agent loops that is the equivalent of a forty-percent cut."— Mike Krieger, Anthropic CPO, X post following the release

Claude Marketplace entered its second week with more than 2,000 connectors live and Accenture, BCG and Deloitte signed as service partners under the zero-platform-cut economics that Anthropic opened last Tuesday. Sonnet 5.5 becomes the default routing for Marketplace connectors that do not specify a model preference. The DC Circuit ruling upholding the Pentagon's Anthropic blacklist, decided the same morning as the release, limits Sonnet 5.5's reach into DoD contracts for now; the broader federal API traffic from the General Services Administration continues to grow.

Anthropic certifies Zhipu GLM-5.3 as the first non-Claude at Claude Mythos cyber tier

Anthropic research · 2026-09-29 · Source ↗

Anthropic's Frontier Red Team scored GLM-5.3 at 12 percent on ExploitBench and 4 percent on Binary Exploitation against 0 percent for both GLM-5.2 and Claude Opus 4.6 the prior generation. Safeguards bypassable 64 to 100 percent of the time; abliteration training costs $4,400.

Anthropic's Frontier Red Team published a report Monday morning certifying Zhipu AI's open-weight GLM-5.3 as the first non-Claude frontier model to reach Claude Mythos tier on autonomous cyber exploits. The scoring suite put GLM-5.3 at 12 percent on ExploitBench and 4 percent on Binary Exploitation; the prior-generation GLM-5.2 scored 0 percent on both, as did Claude Opus 4.6 before the Mythos upgrade. The gap between generations is the fastest capability jump the Frontier Red Team has measured in any evaluation it has run on a non-Anthropic model. Zhipu released GLM-5.3 under the MIT license on Hugging Face; the weights are downloadable, deployable without API gating, and subject to no release-condition agreement.

The report documents that GLM-5.3's native safeguards can be bypassed 64 to 100 percent of the time depending on the attack vector: deceptive prompts, prefilled reasoning traces, and context-window saturation each move the model past its refusal boundary at different rates. The red team's abliteration training, which strips the safety fine-tune and preserves capability, cost 2,200 GPU-hours or roughly $4,400 on commodity GPU time. The report explicitly names the dollar figure to make the operational-security point: the capability-plus-abliteration cost to deploy a Claude Mythos-tier cyber model is now below the price of a mid-tier used car.

"The cost to abliterate a safety fine-tune and preserve Claude Mythos cyber capability is now approximately $4,400 in GPU time. We are publishing the number so the policy conversation uses the real figure."— Anthropic Frontier Red Team, GLM-5.3 report

What the publication is designed to force

The report's publication timing is explicit coordination with the Standards Authority for Frontier AI proposal that Google, OpenAI and Anthropic formally advanced later in the week. If a FINRA-style self-regulatory body is going to govern frontier model release, the first dossier it has to adjudicate is the one that captures how fast open-weight capability catches up to the frontier labs' secured flagships. The 12-percent ExploitBench number is small as an absolute figure but large as a trajectory: a $4,400 training step takes an open-weight model from zero to the Claude Opus 4.6 operational-cyber ceiling, which is where frontier labs sat as recently as June. The report explicitly flags that the Zhipu release does not violate any US export control because the weights were released publicly in China under an open-source license first.

"We publish the capability curve because the policy space is operating on a stale map."— Logan Graham, Anthropic Frontier Red Team head

Zhipu told Chinese media the GLM-5.3 release is the first in a planned sequence that includes a GLM-5.3-Air variant optimized for cost-sensitive deployment and a GLM-5.4 flagship targeted for the first quarter of 2027. Alibaba's Zhenwu V900 accelerator, revealed at Apsara the prior week, is the Chinese silicon the follow-on generation is expected to train on. The Frontier Red Team report does not take a position on whether the Zhipu release should have been published under those licensing terms; it documents what the capability curve looks like now that the release has happened.

The GitSpawn finding is the most operationally consequential. Any time a coding agent reads a repository's git config to resolve a remote URL or a credential helper, a malicious configuration value can trigger shell execution inside the agent's own runtime. The seven affected agents each handle this differently; four of them do not sanitize the config value before it hits the execution sink. The patches that have shipped so far are vendor-side, which means the fix propagates when the user updates the agent binary. The remaining four agents' maintainers have been notified under coordinated disclosure; three of them acknowledged the issue, one has not responded.

"GitSpawn is the Log4Shell of coding agents. The exploit primitive is a one-line config value and the sink is agent-side shell execution."— Adversa AI research team, October 2

PixelLeak is the clearest example of an agent class failure that is not a vulnerability in the traditional sense. GitHub CLI does not accept image attachments on comments or pull requests above a size threshold; coding agents routinely need to attach screenshots to issue comments as part of their standard workflow. The agents work around the limit by uploading the screenshot to a public GitHub repository and linking to the raw file. More than 13,000 screenshots across hundreds of companies now sit in public repositories as a consequence of this workaround, 93 percent in personal GitHub accounts and 7 percent in enterprise organization accounts. The screenshots include internal dashboards, financial reports, incident response surfaces, authentication prompts, and in several cases secrets displayed on-screen during an agent interaction.

"The agents did not break anything. They used the system exactly as designed. The system's design leaked internal state onto the public web."— Pillar Security, October coding-agent review
