Memento 3 clears every public ARC-AGI-3 game at mean RHAE 100.0 with a frozen LLM and a Markdown rulebook

arXiv 2610.11794 · 2026-10-10 · Source ↗

UCL, Huawei Noah's Ark Lab UK and Liverpool paired a frozen LLM with a Markdown rulebook and executable Python world model that revise against observations. Mean RHAE 100.0 across the public harness, 59.3-point lead over Claude Opus 5, 21:0 Pong score with no LLM calls at inference. The code and every ARC-AGI-3 solution opened under MIT on Sunday.

Memento 3, the UCL / Huawei Noah's Ark Lab UK / Liverpool collaboration (arXiv 2610.11794) published Friday, cleared every public ARC-AGI-3 game at a mean RHAE of 100.0 using a frozen LLM paired with a Markdown rulebook and an executable Python world model that both revise against observations. The reported harness-standard lead over Claude Opus 5 is 59.3 points. On the test's Pong game the system scored 21:0 with no LLM calls at inference, operating entirely from the trained rulebook and world-model code paths. The architecture is a departure from end-to-end reinforcement learning: the LLM writes and refines the rulebook on training trajectories, and the inference-time controller executes the Python world model against the current observation to pick the next action.

The UCL and Huawei team opened Memento 3's full code and every ARC-AGI-3 solution on GitHub under MIT on Sunday morning alongside the DeepMind Flamework release (arXiv 2610.11847), which generalizes Memento 3 from one task to task families with no gradient updates. Flamework reports a 61 percent reduction in Atari-suite action count versus per-task Memento 3 at matched final-score rates. Opus 5, Qwen 5 Max and Mistral Large 4 Thinking were all re-tested on the open ARC-AGI-3 harness Sunday afternoon at RHAE 100.0, 99.8 and 99.1 respectively — the first time a frontier LLM paired with the Memento 3 rulebook-and-world-model scaffold has cleared the benchmark.

"The rulebook is a Markdown artifact. The world model is a Python file. The LLM revises both against the trajectory. The result is a 59.3-point lead over Opus 5 with no gradient updates."— Memento 3 abstract, arXiv 2610.11794

Why rulebook-and-world-model matters for the agent conversation

The agent-scaffolding conversation at the frontier for the past year has centered on how much of an agent's reasoning should live inside the model's weights versus how much should live in an external scratchpad. Memento 3's answer is that the external scratchpad can be a human-readable Markdown rulebook plus an executable Python file, and that the LLM's role is to write and refine those artifacts rather than to carry the task's state through its context window. The architecture inverts the pattern from end-to-end RL systems like OpenAI's Dots and the Meta FAIR Muse Spark 1.3 Thinking agent, both of which keep the task state inside the model. The 100.0 mean RHAE across the public ARC-AGI-3 harness is the first time any system has fully cleared it; prior Opus 5 and GPT-6 Astra scores sat in the 40 to 50 range.

"We opened the code because the result reproduces only when the full training loop and inference-time controller are both available. A paper is not enough."— Memento 3 team, GitHub release note, October 11

DeepMind's Flamework builds on Memento 3's architecture by introducing a hierarchical rulebook structure in which an outer rulebook captures task-family invariants and inner rulebooks capture task-specific policies. Flamework reports a 61 percent reduction in Atari-suite action count against per-task Memento 3 at matched final score. The DeepMind authors frame Flamework as the first agent-scaffolding architecture to generalize across task families without gradient updates. The architecture is being pitched as the agent-side counterpart to the structured-decision Jev model: both are explicit bets that the next layer boundary in AI applications is between generative reasoning and executable programmatic structure.
